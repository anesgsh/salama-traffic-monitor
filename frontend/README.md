# Salama – Traffic Monitoring System

A real-time traffic monitoring prototype using lightweight deep learning for traffic sign detection and violation monitoring.

## Features

- Traffic sign and vehicle detection
- Stop-sign violation monitoring
- Real-time dashboard and event visualization
- Detection history and analytics
- OpenVINO INT8 optimized inference

## Requirements

- Python 3.12
- Node.js and npm

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/anesgsh/salama-traffic-monitor.git
cd salama-traffic-monitor
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Start the frontend

```bash
npm run dev
```

### 4. Start the backend

From the project root, follow the backend setup instructions.

## Notes

This project is a prototype. Its authentication mechanism is demonstration-only and is not suitable for protecting production systems or sensitive data.
